# EZ-passwd-Generator

Tkinterを使用した**パスワード生成アプリケーション**です。
GUIを備えており、
- **パスワードの長さ指定**
- **文字種別の選択**（安全な記号、特殊記号、大文字、数字）
- **自動コピー機能**
- **設定の保存と読み込み**
などを、ひとつの画面から行うことができます。

## 特徴
1. **カスタマイズ可能な文字種別**
   - 安全な記号（`-._@`）と特殊記号を分離
   - 大文字、数字の使用有無を個別に設定可能

2. **柔軟な長さ指定**
   - パスワードの長さを自由に指定可能
   - 不正な入力値に対するエラー処理

3. **クリップボード連携**
   - 生成したパスワードを即座にコピー可能
   - 生成時の自動コピー機能

4. **設定の永続化**
   - すべての設定をJSONファイルとして保存
   - アプリ起動時に前回の設定を自動読み込み

## セットアップ
1. **このリポジトリをクローンまたはダウンロード**

2. **ライブラリのインストール**
   ```bash
   pip install pyperclip
   ```
   - tkinterは標準ライブラリですが、Mac環境では別途インストールが必要な場合があります
   - その場合は `brew install python-tk` などを実行してください

3. **アプリケーションの起動**
   ```bash
   python main.py
   ```

## 使い方
1. **パスワードの長さ指定**
   - テキストボックスに希望する長さを入力

2. **文字種別の選択**
   - 「安全な記号を含める」（-._@）
   - 「特殊記号を含める」（その他の記号）
   - 「大文字を含める」
   - 「数字を含める」
   - 「生成時に自動コピー」

3. **パスワード生成**
   - 「生成」ボタンをクリックしてパスワードを生成
   - 生成されたパスワードは表示エリアに表示

4. **クリップボードへのコピー**
   - 「コピー」ボタンで手動コピー
   - 自動コピーを有効にしている場合は生成時に自動的にコピー

## 設定ファイル (`config.json`) について
- アプリ終了時に同階層に `config.json` が作成されます
- 例:
  ```json
  {
      "length": "12",
      "use_safe_symbols": true,
      "use_special_symbols": false,
      "use_uppercase": true,
      "use_numbers": true,
      "auto_copy": false
  }
  ```
